# 大学知识题库 API

一个可以直接跑起来的中文题库检索服务：**多源在线检索 + 本地离线兜底**，返回结构对齐 OCS 网课助手订阅格式，也能被任何 HTTP 客户端调用。

本地保留两份题库：**248 道「大学生成长」主题题**（C-Eval 筛选 234 道 + 补充判断题 14 道）和 **78 道高等数学题**（选择 + 判断，计算类入库时由 sympy 逐题复核）。文字题优先走 GitHub 开源项目 [tikuAdapter](https://github.com/DokiDoki1103/tikuAdapter) 接入的公开题库源，数学题一律本地算，全部不中才判定为未找到。

> 演示实例：`https://a8d93c5821aaa7c93.app.workbuddy.host/?sharecode=6QCZCGX2NG`（临时部署，可能随时下线，请以自行部署为准）

## 特性

- **多源降级**：`buguake → icodef → local/gaoshu` 按优先级依次检索，`trace` 字段暴露每个源的命中数和最高相似度
- **图片题**：接 OCS 5.1+ 的 `env.images`，服务端 OCR 出文字再检索（可选依赖，装了才生效）
- **数学题**：**不走在线源**。能解析出表达式就用 sympy 直接算（极限 / 定积分 / 极值 / 行列式 / 求导 / 偏导 / 级数敛散 / 极值拐点 / 判断题校验），**算出值与选项完全一致才返回**；算不了的查本地高数题库；都没有就 404，不猜
- **离线可用**：断网或在线源超时时自动落到本地 326 题 + 本地计算，不依赖外网
- **答案格式友好**：多选题统一输出 `A#B#D`（OCS 要求的形态），判断题输出 `正确 / 错误`；答案若是选项原文（如 `4/3`），会用 OCR 到的选项反查回字母
- **开箱即用**：单文件 FastAPI 服务，无需数据库，`python3 server.py` 即可
- **可视排查**：每次检索返回 `trace`，一眼看出是哪个源命中、阈值差多少

## 快速开始

```bash
git clone https://github.com/lu-kaixin/daxue-quiz-api.git
cd daxue-quiz-api
pip install -r requirements.txt
python3 server.py          # 默认 0.0.0.0:8765
```

可选环境变量：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | `8765` | 监听端口 |
| `PUBLIC_BASE` | 空 | 对外访问地址，用于生成订阅里的绝对 URL |
| `SHARECODE` | 空 | 访问口令，配置后所有请求需带 `?sharecode=xxx` |

验证：

```bash
curl http://127.0.0.1:8765/health
# {"ok":true,"local":248,"sources":5,"version":"2.6","ocr":true,"math":true}
```

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET / POST | `/search` | 检索入口，`?q=关键词` 或 `{"q":"关键词"}` |
| GET | `/search/{keyword}` | 关键词放路径，兼容不支持 query 的客户端 |
| GET | `/api/daxue/meta` | 题库元信息、来源、模块、许可 |
| GET | `/api/daxue/sources` | 各源优先级、端点、缓存状态 |
| GET | `/api/daxue/questions` | 题目列表（默认不含答案），支持 `module` `type` `q` `limit` `offset` |
| GET | `/api/daxue/questions/{id}` | 单题详情 |
| GET | `/api/daxue/random` | 随机抽题（不含答案） |
| POST | `/api/daxue/check` | 判分，传 `{"id":"...","option":1}` |
| GET | `/api/daxue/export` | 整库导出（含答案） |
| GET | `/subscribe` | OCS 订阅配置（2 条） |
| GET | `/subscribe/generic` | 通用订阅配置（`{keyword}` 占位符） |
| POST | `/ocr` | 只识别图片文字，不检索 |
| GET | `/math` | 数学求解能力说明（支持哪些题型、什么情况下拒答） |
| GET | `/health` | 健康检查，含 `ocr` / `math` 两个能力位 |

### 检索示例

```bash
curl -X POST http://127.0.0.1:8765/search \
  -H "Content-Type: application/json" \
  -d '{"q":"没有现实可行性的目标不算目标"}'
```

```json
{
  "code": 0,
  "msg": "ok",
  "keyword": "没有现实可行性的目标不算目标",
  "origin": "buguake",
  "score": 0.853,
  "data": {
    "question": "没有现实可行性的目标其实不算目标。",
    "answer": "正确",
    "answer_letter": "A",
    "answer_ocs": "正确",
    "type": "judge"
  },
  "trace": [
    { "source": "buguake", "hits": 10, "top": 0.853, "used": true }
  ]
}
```

未命中时返回 `code: 404`、`data: null`，客户端应据此放弃而不是把空对象当答案。

### 指定来源

```bash
curl "http://127.0.0.1:8765/search?q=关键词&source=local"    # 只查本地
curl "http://127.0.0.1:8765/search?q=关键词&source=all&count=3"  # 全源，取多条
```

`source` 可选 `auto`（默认）、`buguake`、`icodef`、`local`、`gaoshu`、`all`。

## 检索机制

| 优先级 | 来源 | 类型 | 返回 | 相似度阈值 |
|---|---|---|---|---|
| 1 | 不挂科题库源（GitHub · tikuAdapter） | 在线 | 题干 + 答案 | 0.72 |
| 2 | 言溪题库（GitHub · tikuAdapter） | 在线 | 仅答案 | 0.90 |
| 3 | 本地 C-Eval 大学知识题（248 道） | 离线 | 题干 + 答案 + 解析 | 0.72 |
| 4 | 本地高等数学题库（78 道） | 离线 | 题干 + 选项 + 答案 + 解析 | 0.72 |
| 5 | 本地符号计算（sympy） | 离线 | 计算结果 → 选项字母 | 与选项精确相等 |

数学题不参与上面的在线检索：只要 `is_math` 判定为数学题，就只在「本地计算 → 本地高数题库」之间找答案。

言溪只回传答案、没有题干可比对，所以阈值抬到 0.90 防误配。相似度算法为 NFKC 归一化 + 去标点/停用词后的字符级匹配。

**数学题另走一套判定**：先统一符号（`×→*`、`÷→/`，`²→2`、`₀→0`），再抽「字母词 + 数字 + 运算符」做指纹；两边数字序列必须完全一致，指纹重合度过半才算同一题。不满足直接 0 分 —— `lim(x→0) sin3x/x` 与 `lim(x→0) sinx/x` 字面相似度 0.75，但答案一个是 3 一个是 1，只有这道闸能挡住。

同一题干常有多个版本（`ABD`、`A,B,D`、选项原文无分隔拼接）。服务会在同分候选中优先选择字母答案，保证客户端能正确拆分多选。

## 图片题

OCS 5.1 起会把题干里的图片转成 base64 塞进 `env.images`，题干对应位置留下 `[图片1]` 占位符。订阅配置里用 handler 把图片取出来一并发给 `/search`，服务端 OCR 出文字、拼回题干再检索。

### 启用

```bash
pip install rapidocr-onnxruntime   # 约 50 MB，含 onnxruntime 与内置模型
```

不装也能跑，`/health` 里 `ocr` 是 `false`，文字题完全不受影响。

### 接口

```bash
POST /search
{
  "title": "[图片1]",
  "type": "single",
  "images": ["data:image/png;base64,..."]
}
```

响应会多一个 `ocr` 字段，方便排查：

```json
{
  "code": 0,
  "keyword": "时期是确立理想信念最集中和突出的时期。",
  "origin": "local",
  "ocr": {"count": 1, "lines": ["...", "A.少年", "B.青年"], "stem": "...", "option_lines": ["A.少年", "B.青年"], "math": false}
}
```

也可以单独调 `POST /ocr` 只做识别，不检索。

### 检索顺序

| 情况 | 走法 |
|---|---|
| 能解析成表达式的数学题 | 本地 sympy 直接算，算出的值与某个选项完全一致才返回 |
| 判断题 / 概念选择（可验算） | 先做命题校验，再用题干骨架查本地高数题库 |
| 本地 326 题里有同题（相似度 ≥ 0.90，且选项要对得上） | 返回本地答案 |
| 以上都没有（且不是数学题） | 走两个在线源 `buguake → icodef`，答案若是「字母 + 选项原文」，用原文回本页选项反查字母 |
| 都拿不到，或在线答案的选项文本与本页选项对不上 | 返回 404，不猜 |

本地命中要求「题干相似度 ≥ 0.90 **且** 选项重合度 ≥ 0.34」：题库里同一道题干常有选项顺序不同的多个版本，按页面给的选项选版本，才不会把 B 版的答案填到 A 版上。

### 实现要点

- **小图先放大再识别**：长边小于 1200px 时放大 2 倍，上标、积分号、根号这类小符号最容易糊掉。
- **过滤章节标题**：`9.3「考碗」一族章节测验` 这类行会污染检索词，识别后丢弃。
- **题干去重**：题干本身有文字、图片又渲染了同一段时，不重复拼接。
- **答案反查字母**：题库常回 `4/3` 这种选项原文，用 OCR 到的选项行反查回 `A`，OCS 才能自动勾选。
- **上限**：单题最多 3 张图、单张 8 MB，行置信度低于 0.55 丢弃。

### 识别能力的实际边界

| 图片内容 | 结果 |
|---|---|
| 整段文字排成图片、常规选择题截图 | 能识别，准确率高 |
| 中文主体 + 简单公式（`lim`、`sin3x/x`、`x²+2x`、分数） | 主体能认，公式偶有错字；配合本地计算多数能算对 |
| 积分上下限 `∫₀¹` | **容易丢**，符号常被认成 `≥`/`×`，这道题多半算不出来 |
| 上标（`x³` 认成 `x²`） | 偶发。数学指纹会因此判为「不是同一题」，返回 404 而不是错答 |
| 电路图、几何图、化学结构式 | 无文字可识别，做不了 |
| 表格截图 | 勉强，容易串行 |

OCR 的固有限制不会因为换库消失。想彻底解决只能上视觉大模型（按量计费），本服务不接。

## 数学题

两个在线源背后是网课人文题库，工科数学覆盖极低 —— 实测 8 道典型高数题，**0 道命中**，其中 2 道还会匹配到「换了个系数」的另一道题（`sin3x/x` 匹配到 `sinx/x`，答案从 3 变成 1）。更糟的是，没被指纹拦住的题会被答错：`微分方程 y'=2x 的通解` 被答成 `y=2x+C`，`两个无穷小量之和仍是无穷小量` 被答成「错」。

所以 2.6 起定了一条硬规则：**数学题一律不走在线源**。三条本地路径，逐级下降：

**第一层：本地符号计算。** 能解析出表达式就先算：

```bash
pip install sympy     # 约 12 MB，纯 Python，无模型下载
```

| 题型 | 例子 | 结果 |
|---|---|---|
| 极限 | `lim(x→0) sin3x/x` | 3 |
| 定积分 | `∫₀¹ (x²+2x)dx` | 4/3 |
| 广义积分 | `∫_0^1 1/x² dx` 是否收敛 | 发散 |
| 极值 | `y=x³-3x²+2 的极小值` | -2 |
| 极值/拐点判别 | `y=x³ 在 x=0 处` | 拐点 |
| 行列式 | `|1 2; 3 4|` 或 `[[1,2],[3,4]]` | -2 |
| 导数 | `f(x)=x²+3x，f'(1)` | 5 |
| 偏导数 | `z=x²y，∂z/∂x` | 2xy |
| 级数敛散 | `下列级数中收敛的是`（逐项 p-判别/积分判别） | 唯一收敛项 |
| 组合概率 | `5 白 3 黑任取 2 个，至少 1 个白` | 25/28 |
| 映射原像 | `f:(x,y)→(x+2y,2x-y)`，求 (3,1) 的原像 | (1, 1) |
| 映射个数 | A={1,2,3,4}、B={a,b,c}，A 到 B 的映射个数 | 81（3⁴） |
| 判断题校验 | `∫_(-1)^1 1/x dx = 0` / `y=|x| 在 x=0 处可导` | 错误 / 错误 |

规则只有一条：**算出来的值必须与识别到的某个选项完全一致（误差 1e-9）才返回**。算得出但对不上选项，说明题目被识别残了，直接 404。

**第二层：本地高数题库。** 78 道选择题 + 判断题，覆盖极限、连续、导数、中值定理、不定积分/定积分、级数、微分方程、多元微分。计算类题目在入库时就由 sympy 复核过答案，不是手工抄的。

**第三层：404。** 定理型判断（`若 f'(x0)=0，则 x0 一定是极值点`）不做逻辑推理 —— 这种题靠的是背定义，符号计算给不出可靠结论，只能靠题库命中；题库里没有就返回未收录。

### 实测（2.6）

| 测试集 | 题量 | 对 | 错 | 未答 |
|---|---|---|---|---|
| 高数典型题（极限/积分/级数/判断等） | 30 | 30 | 0 | 0 |
| 本地高数题库全量自检 | 78 | 78 | 0 | 0 |
| 未入库新题（考泛化） | 15 | 15 | 0 | 0 |
| 原有大学知识题全量自检 | 248 | 248 | 0 | 0 |

2.5 的同一套 20 题里，判断题 3 错 2 未答；2.6 全部答对。差别来自三处：数学题不再交给在线源、新增判断题校验器、新增高数题库。

### 覆盖不到

几何证明、应用题建模、含参讨论、矩阵运算（只做行列式）、抽象级数（含 `u_n` 符号的通项）—— 这些要靠语义理解，符号计算做不了，会返回 404。

单射 / 满射 / 双射这类**概念辨析题**也不做：「下列对应关系中是满射的是」要逐个读选项的定义域、陪域和对应法则再判值域，符号计算给不出可靠结论，宁可 404。

另外在线源的选项顺序常和本校卷子不同（同一道原像题，题库里有 `B.(1,1)`、`C.(1,1)`、`D.(1,1)` 三个版本），所以拿到答案后一律用**选项原文**回本页选项反查字母；原文对不上就判不可信，不照抄字母。

## 接入 OCS 网课助手

订阅地址：`http://你的域名:8765/subscribe`，整段 JSON 粘贴到题库配置即可。也可以直接使用 [`ocs-subscription.json`](ocs-subscription.json)。

**必须先在脚本里加域名白名单**，否则请求会被 Tampermonkey 拦截：

1. Tampermonkey 面板 →「OCS 网课助手」→ 编辑
2. 在 `// ==UserScript==` 元信息块中追加：`// @connect 你的域名`
3. `Ctrl + S` 保存，刷新课程页

OCS 的字段与通用 HTTP 客户端不同，注意这几点：

| 项 | OCS 要求 |
|---|---|
| 请求体字段 | `data`（不是 `body`） |
| 题目占位符 | `${title}`（不是 `{keyword}`） |
| 请求类型 | `type: "GM_xmlhttpRequest"`，`@connect` 只对它生效 |
| 多选答案 | 必须 `A#B#D`，不能是数组或 `ABD` |

## 已知限制

- 本地库不含时间管理、社团实践、创业理财、职业规划类题目 —— C-Eval 里没有，未用非开源来源批量填充。
- 在线源依赖第三方接口，稳定性不可控；对稳定性要求高时建议 `?source=local` 只用本地库。
- 相似度阈值按经验设定，极端表述（口语化改写）可能命中不到，此时返回 404 而非猜测答案。
- 两个在线源对工科数学覆盖极低，数学题只走本地计算与本地题库；能算的只有「可解析表达式」那几类，应用题、证明题、抽象级数会 404。
- 高数题库 78 道覆盖的是教材常见题型，不等于本校题库；没命中的题会走计算，计算也不支持的返回 404。
- 图片题依赖 OCR：`∫₀¹` 这类上下标容易丢，`x³` 可能认成 `x²`；识别残缺时服务会返回 404，不会用错答案凑数，但也就答不出来。
- 本地计算与在线检索的阈值都是经验值，覆盖不到长尾题型；遇到 404 请以课程原文为准。
